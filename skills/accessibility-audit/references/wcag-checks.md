# Default checks

These map to common WCAG 2.2 expectations. A pass here is not a conformance statement.

- 2.1.1 Keyboard: every new action works without a pointer.
- 2.4.7 Focus Visible: focus is visible on the controls you tab through.
- 2.4.3 Focus Order: order matches the visual and reading order, or the exception is explained.
- 4.1.2 Name, Role, Value: the control's accessible name matches its purpose.
- 1.4.3 Contrast: text you changed is at least 4.5:1, or large text 3:1. Record the values.
- 1.4.1 Use of Color: state is not color-only.
- 3.3.1 Error Identification: errors say what failed.
- 3.3.2 Labels or Instructions: required fields are labeled before the user submits.
- 2.4.11 Focus Not Obscured: the focused control is not fully hidden behind a sticky bar. Mark not-run if you cannot scroll the page.

Mark anything you did not do as not-run.
